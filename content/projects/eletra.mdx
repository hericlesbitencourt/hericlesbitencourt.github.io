## [React/TypeScript/Python/Django] Wind Turbine Blade Wear Prediction System

### Project Overview:
Contributed to the maintenance, bug fixing, and deployment of a high-security software system for a wind turbine blade wear prediction project in the hydroelectric industry. Operated in an offline, tightly controlled environment, deploying updates for both the React front-end and Django back-end. Ensured the system functioned seamlessly in both development and production environments on an IIS server, overcoming restrictions such as the lack of direct internet access.

### Achievements:

- **Diagnosed and resolved critical bugs, maintaining a stable and reliable codebase for production use**
- **Deployed front-end and back-end artifacts to a secure IIS server, adhering to stringent security protocols**
- **Utilized Django APScheduler to ensure scheduled tasks operated reliably in both environments**
- **Coordinated secure artifact transfers, performing integrity checks for successful deployment**
- **Introduced incremental enhancements to the React front-end for improved usability**

### Technologies/Tech Stack:
**React, TypeScript, Python, Django, Django REST Framework, PostgreSQL, IIS, Shell Scripting, styled-components**
