## [React Native/TypeScript] Ictus Power Meter

### Project Overview:
Developed a cross-platform mobile application for professional cyclists to interface with a Bluetooth-enabled power meter device. Built with React Native, the app provided real-time power metrics and performance insights, leveraging AWS services for secure data storage and processing. Successfully deployed to both the Google Play Store and Apple App Store, delivering a seamless experience for end users.

### Achievements:

- **Designed and implemented a React Native mobile interface for real-time cycling power metrics**
- **Integrated AWS services including S3, DynamoDB, Lambda, and API Gateway for data management**
- **Successfully deployed the app to both Play Store and App Store with compliance to platform requirements**
- **Collaborated with firmware engineers to ensure seamless Bluetooth communication**
- **Optimized app performance, reducing latency and improving responsiveness under varying network conditions**

### Technologies/Tech Stack:
**React Native, TypeScript, AWS, Amazon S3, Amazon DynamoDB, AWS Lambda, API Gateway, Bluetooth, styled-components**
