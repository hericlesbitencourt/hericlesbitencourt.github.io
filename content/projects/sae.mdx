## [Vue.js/TypeScript/Spring Boot] Wi-SUN Network Simulation Tool

### Project Overview:
Developed a comprehensive simulation tool for Wi-SUN network devices, designed to help users visualize device locations and network topology on an interactive map. The project combined a robust Vue.js front-end with Leaflet for mapping, and a Spring Boot back-end with OracleDB for data management and simulations.

### Achievements:

- **Designed and implemented a Vue.js front-end integrated with Leaflet for real-time visualization**
- **Built and maintained Spring Boot microservices for CRUD operations and network simulation logic**
- **Integrated OracleDB to securely store device configurations and simulation parameters**
- **Enhanced user authentication mechanisms and implemented basic security measures**
- **Improved team workflows by introducing and maintaining Swagger documentation**

### Technologies/Tech Stack:
**Vue.js, TypeScript, Spring Boot, OracleDB, Leaflet, Linux, PostgreSQL, Shell Scripting, Vuex, axios**
