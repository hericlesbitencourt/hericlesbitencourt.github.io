## Texas Affinity - Affinity APP

### Project Overview:
Built a CRM application for an insurance company with React, Laravel and MariaDB. The application included a data import feature that significantly enhanced overall productivity by reducing to 0% the necessity of sending informative emails.

### Achievements:

- **Successfully developed a comprehensive CRM solution for an insurance company**
- **Implemented a data import feature that eliminated the need for informative emails**
- **Enhanced overall productivity through streamlined data management processes**

### Technologies/Tech Stack:
**React, TypeScript, PHP, Laravel, MariaDB, REST APIs, SQL, MySQL, Object-Oriented Programming**
