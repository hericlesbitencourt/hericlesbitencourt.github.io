## [Python/Django] Dispatch Optimization System

### Project Overview:
Developed and maintained the web interface for communication with the Dispatch Optimization System (SOD) used at the substation on Fernando de Noronha Island. The web system, built with Django, was designed to integrate with external APIs and simulate data from diesel generators using a proprietary program, ActionView. The project required precise execution in a remote environment with limited internet connectivity and communication.

### Achievements:

- **Updated and maintained the Django codebase for seamless communication with external APIs**
- **Integrated and maintained MATLAB scripts for periodic job execution using Django APScheduler**
- **Authored a detailed deployment manual for system implementation in challenging remote environments**
- **Executed deployment and system tests on-site, ensuring 100% functionality despite limited internet**
- **Conducted rigorous testing to validate system stability and accuracy of data exchange**

### Technologies/Tech Stack:
**Python, Django, MATLAB, CSS, IIS, JavaScript, APScheduler**
